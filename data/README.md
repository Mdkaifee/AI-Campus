# DAVIET knowledge base (JSON)

Place verified college information here as JSON files.

Each entry includes at minimum:
- title
- category
- content
- source_url
- updated_at
- keywords

Do not invent faculty names, fees, timings, or contact numbers.
If a fact is missing from an official source, leave it empty or mark it for verification.

Source site: https://davietjal.org

Current files are populated from official pages scraped/verified on 2026-09-26.
Re-check time-sensitive details (fees, committee members, packages) before demos.
